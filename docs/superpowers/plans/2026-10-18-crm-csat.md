# CRM CSAT («Мы смогли вам помочь?») — ops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After an operator resolves a ticket, the customer gets «Мы смогли вам помочь?» with 👍/👎 (Telegram buttons; web via an ops API the Turkarta webapp calls). After 👎, an optional comment. Ratings show in the ticket timeline and in stats (team, per operator, per topic).

**Architecture:** New feature module `src/crm/csat.ts` (ask, rate, comment, lookups) and migration `0020_crm_csat.sql`. Asked from `setStatus` right after the resolve message, sent through the existing `sendSystemText` → `deliver` path, which gains optional Telegram `reply_markup`. The bot wires one `csat:` callback handler and one comment intercept in the DM handler. `src/server.ts` web API gets a `csat` field and one POST route. Stats extend the existing `stats()`; the CRM web shows them. The Turkarta webapp widget is a separate plan in the Turkarta repo.

**Tech Stack:** Node 22 TS, Hono, grammY, zod, postgres.js, node:test; React + vitest in `web/`.

**Spec:** `docs/superpowers/specs/2026-10-18-crm-quality-design.md` §2 (CSAT). Owner decision 2026-10-18: question text «Мы смогли вам помочь?».

## Global Constraints

- Worktree `~/projects/turkarta-operations-video`, branch `feat/crm-csat` off `main`. Never touch `~/projects/turkarta-operations` or `~/projects/turkarta-operations-crm`. Commit only the task's files with explicit `git add <path>`; never `-A`/`.`; never bare `git stash`. No new dependencies.
- Migration idempotent (boot-applied in one transaction), appended to `CRM_MIGRATIONS` in `src/db.ts`.
- Asked only when: resolved via CRM `setStatus` (never cutover/bulk), `csat_enabled`, not legacy Bitrix surface, the ticket has at least one `actor_type='human'` message after its last `reopened` event (or ever, if never reopened), and no `crm_csat` row exists for this `(ticket_id, resolved_at)`.
- The prompt message is `sender='agent'`, `actor_type='automation'`, `author_id='crm:system'`, `kind='text'`, body = `csat_text`. It never triggers AI triage/review.
- A rating or comment is accepted only from the ticket's own customer (Telegram `user_tg`, or web `web_user_id`) and only while the ticket is still resolved with the same `resolved_at` (a reopen closes the survey). A comment needs rating `down`.
- A Telegram comment is a message that **replies to the bot's comment prompt**; anything else follows the normal path (reopen / new ticket).
- Copy (exact): question default «Мы смогли вам помочь?»; buttons «👍 Да», «👎 Нет»; after tap «Спасибо за оценку!»; comment prompt «Что пошло не так? Ответьте на это сообщение — это необязательно.»; after comment «Спасибо, передали команде.»; stale tap «Оценка уже не принимается.».
- Customer text never appears in logs.
- Tests: backend `pnpm build && CRM_TEST_DATABASE_URL=postgres://postgres@127.0.0.1:5433/crm_test node --experimental-test-module-mocks --import tsx --test tests/<file>` (one Postgres file at a time); full `CRM_TEST_DATABASE_URL=postgres://postgres@127.0.0.1:5433/crm_test pnpm test`; `pnpm typecheck`; web `cd web && pnpm test && pnpm typecheck && pnpm build`. Testing Library normalizes NBSP in DOM text but not in matcher strings.

## Review Focus

1. Someone else's or a stale survey (wrong user, ticket reopened or re-resolved): refused, nothing changes (Task 1 tests).
2. A plain Telegram message after 👎 (not a reply to the prompt) must reopen/create normally, not be eaten as a comment (Task 2 test).
3. Existing tests that resolve tickets with human replies must not start hitting Telegram: CSAT goes through the injected transport / bot API interceptor (Task 1 Step "existing tests").
4. Double tap / double POST: idempotent, one event (Task 1 tests).
5. Stats with fewer than 5 answers: numbers returned, UI shows «мало оценок» (Tasks 3–4).

```sql
-- CSAT after a CRM resolve (spec 2026-10-18 §2). Applied on every boot: idempotent.
create table if not exists public.crm_csat (
  id uuid primary key default gen_random_uuid(),
  ticket_id uuid not null references public.support_requests(id) on delete cascade,
  resolved_at timestamptz not null,
  operator_id bigint references public.crm_operators(id),
  channel text not null check (channel in ('telegram','web')),
  prompt_message_id uuid references public.support_messages(id) on delete set null,
  comment_prompt_tg_id bigint,
  rating text check (rating in ('up','down')),
  comment text check (comment is null or char_length(comment) <= 1000),
  asked_at timestamptz not null default now(),
  answered_at timestamptz,
  commented_at timestamptz,
  unique (ticket_id, resolved_at)
);
create index if not exists crm_csat_resolved_idx on public.crm_csat (resolved_at);
do $$ begin
  if not exists (select 1 from pg_constraint
                  where conname = 'crm_ticket_events_type_check' and pg_get_constraintdef(oid) like '%csat%') then
    alter table public.crm_ticket_events drop constraint if exists crm_ticket_events_type_check;
    alter table public.crm_ticket_events add constraint crm_ticket_events_type_check
      check (type in ('created','assigned','auto_assigned','unassigned','taken_over','status_changed','reopened','topic_changed','csat'));
  end if;
end $$;
```

```ts
import type postgres from "postgres";
import { sql, type Ticket } from "../db.js";
import { publish } from "./events.js";
import { sendSystemText, type ReplyDeps } from "./reply.js";
import { logEvent } from "./tickets.js";

export type Rating = "up" | "down";
export type CsatWho = { userTg: number } | { webUserId: string };
export const CSAT_UP = "👍 Да";
export const CSAT_DOWN = "👎 Нет";
export const CSAT_THANKS = "Спасибо за оценку!";
export const CSAT_ASK_COMMENT = "Что пошло не так? Ответьте на это сообщение — это необязательно.";
export const CSAT_COMMENT_THANKS = "Спасибо, передали команде.";
export const CSAT_CLOSED = "Оценка уже не принимается.";
const COMMENT_MAX = 1000;
const UUID_RE = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

type Sql = postgres.Sql | postgres.TransactionSql;

/** A human operator answered in the current cycle (after the last reopen). */
async function humanAnswered(ticketId: string): Promise<boolean> {
  const [r] = await sql`
    select exists (
      select 1 from support_messages m
       where m.ticket_id = ${ticketId} and m.actor_type = 'human'
         and m.created_at > coalesce((select max(e.created_at) from crm_ticket_events e
                                       where e.ticket_id = ${ticketId} and e.type = 'reopened'), '-infinity'::timestamptz)
    ) as ok`;
  return r?.ok === true;
}

/** Asks once per resolution. Returns the survey id, or null when it is not asked. */
export async function askCsat(ticket: Ticket, text: string, deps: ReplyDeps = {}): Promise<string | null> {
  if (ticket.status !== "resolved" || !ticket.resolved_at || !(await humanAnswered(ticket.id))) return null;
  const [row] = await sql<{ id: string }[]>`
    insert into crm_csat (ticket_id, resolved_at, operator_id, channel)
    values (${ticket.id}, ${ticket.resolved_at}, ${ticket.assigned_operator_id ?? null},
            ${ticket.user_tg != null ? "telegram" : "web"})
    on conflict (ticket_id, resolved_at) do nothing
    returning id`;
  if (!row) return null;
  const keyboard = { inline_keyboard: [[
    { text: CSAT_UP, callback_data: `csat:${row.id}:up` },
    { text: CSAT_DOWN, callback_data: `csat:${row.id}:down` },
  ]] };
  const messageId = await sendSystemText(ticket, text, deps, { reply_markup: keyboard });
  await sql`update crm_csat set prompt_message_id = ${messageId} where id = ${row.id}`;
  return row.id;
}

type Locked = { id: string; ticket_id: string; rating: Rating | null; open: boolean };

/** Locks the survey for its own customer; `open` = the ticket is still in the resolution that was asked about. */
async function lockFor(tx: Sql, id: string, who: CsatWho): Promise<Locked | null> {
  if (!UUID_RE.test(id)) return null;
  const owner = "userTg" in who ? tx`r.user_tg = ${who.userTg}` : tx`r.web_user_id = ${who.webUserId}`;
  const [r] = await tx<Array<Locked>>`
    select c.id, c.ticket_id, c.rating, (r.status = 'resolved' and r.resolved_at = c.resolved_at) as open
      from crm_csat c join support_requests r on r.id = c.ticket_id
     where c.id = ${id} and ${owner}
       for update of c`;
  return r ?? null;
}

export async function rateCsat(id: string, who: CsatWho, rating: Rating):
  Promise<{ ok: true; askComment: boolean } | { ok: false; reason: "not_found" | "closed" }> {
  const res = await sql.begin(async (tx) => {
    const c = await lockFor(tx, id, who);
    if (!c) return { ok: false as const, reason: "not_found" as const };
    if (!c.open) return { ok: false as const, reason: "closed" as const };
    if (c.rating === rating) return { ok: true as const, changed: false, ticketId: c.ticket_id };
    await tx`update crm_csat set rating = ${rating}, answered_at = now() where id = ${id}`;
    await logEvent(tx, c.ticket_id, "csat", null, { rating });
    return { ok: true as const, changed: true, ticketId: c.ticket_id };
  });
  if (!res.ok) return res;
  if (res.changed) await publish({ type: "ticket.updated", ticketId: res.ticketId });
  return { ok: true, askComment: rating === "down" };
}

export async function commentCsat(id: string, who: CsatWho, comment: string):
  Promise<{ ok: true } | { ok: false; reason: "not_found" | "closed" | "invalid" }> {
  const text = comment.trim();
  if (!text || text.length > COMMENT_MAX) return { ok: false, reason: "invalid" };
  const res = await sql.begin(async (tx) => {
    const c = await lockFor(tx, id, who);
    if (!c) return { ok: false as const, reason: "not_found" as const };
    if (!c.open) return { ok: false as const, reason: "closed" as const };
    if (c.rating !== "down") return { ok: false as const, reason: "invalid" as const };
    await tx`update crm_csat set comment = ${text}, commented_at = now() where id = ${id}`;
    await logEvent(tx, c.ticket_id, "csat", null, { rating: "down", comment: text });
    return { ok: true as const, ticketId: c.ticket_id };
  });
  if (!res.ok) return res;
  await publish({ type: "ticket.updated", ticketId: res.ticketId });
  return { ok: true };
}

export async function setCommentPrompt(id: string, tgMessageId: number): Promise<void> {
  await sql`update crm_csat set comment_prompt_tg_id = ${tgMessageId} where id = ${id}`;
}

/** The survey whose comment prompt this Telegram message replies to, for that same customer. */
export async function csatByCommentPrompt(userTg: number, replyToMessageId: number): Promise<string | null> {
  const [r] = await sql<{ id: string }[]>`
    select c.id from crm_csat c join support_requests r on r.id = c.ticket_id
     where c.comment_prompt_tg_id = ${replyToMessageId} and r.user_tg = ${userTg} and c.rating = 'down'
     limit 1`;
  return r?.id ?? null;
}

/** The open survey of a resolved web ticket, for the web chat poll. */
export async function csatForWeb(ticketId: string): Promise<{ id: string; rating: Rating | null; comment_allowed: boolean } | null> {
  const [r] = await sql<Array<{ id: string; rating: Rating | null; comment: string | null }>>`
    select c.id, c.rating, c.comment from crm_csat c join support_requests r on r.id = c.ticket_id
     where c.ticket_id = ${ticketId} and r.status = 'resolved' and r.resolved_at = c.resolved_at`;
  return r ? { id: r.id, rating: r.rating, comment_allowed: r.rating === "down" && r.comment === null } : null;
}
```

const WebCsatPayload = z.object({
  csat_id: z.string().uuid(),
  web_user_id: z.string().min(1),
  rating: z.enum(["up", "down"]).optional(),
  comment: z.string().max(1000).optional(),
}).refine((p) => p.rating !== undefined || p.comment !== undefined);

app.post("/api/support/web/csat", async (c) => {
  if (!appAuthed(c)) return c.json({ error: "forbidden" }, 403);
  const parsed = WebCsatPayload.safeParse(await c.req.json().catch(() => null));
  if (!parsed.success) return c.json({ error: "invalid" }, 422);
  const { csat_id, web_user_id, rating, comment } = parsed.data;
  const who = { webUserId: web_user_id };
  const fail = (reason: "not_found" | "closed" | "invalid") =>
    c.json({ error: reason }, reason === "not_found" ? 404 : reason === "closed" ? 409 : 422);
  if (rating) {
    const r = await rateCsat(csat_id, who, rating);
    if (!r.ok) return fail(r.reason);
  }
  if (comment !== undefined) {
    const r = await commentCsat(csat_id, who, comment);
    if (!r.ok) return fail(r.reason);
  }
  return c.json({ ok: true });
});
